## 🚀 One-Click Deployment Options

### Option 1: GitHub Pages (Recommended - Free & Permanent)

1. Create a new repository on your GitHub account ([github.com/new](https://github.com/new)) named `portfolio` (or `impulkit77.github.io`).
2. Run the following commands in this directory:
   ```bash
   git remote add origin https://github.com/Impulkit77/portfolio.git
   git branch -M main
   git push -u origin main
   ```
3. In your GitHub repository:
   - Go to **Settings** > **Pages**
   - Under **Build and deployment > Source**, select **Deploy from a branch**
   - Branch: `main` / folder: `/ (root)`
   - Click **Save**.
   - Your site will be live at: **`https://impulkit77.github.io/portfolio/`**

### Option 2: Vercel (Instant HTTPS)

Run non-interactive deployment via `npx`:
```bash
npx vercel
```
Or import the GitHub repository in [vercel.com](https://vercel.com) for automatic deployments on push.

### Option 3: Netlify

Run non-interactive deployment:
```bash
npx netlify-cli deploy --prod --dir=.
```
Or drag and drop this project folder directly onto [app.netlify.com/drop](https://app.netlify.com/drop).
